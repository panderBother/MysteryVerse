# Storage Adapters

`Repository` is the reusable persistence boundary for Phase 0 data
infrastructure. Domain modules should depend on narrow interfaces and map
these storage records into domain values. HTTP handlers must not call
`sqlc.Queries` directly.

Implementation rules:

- SQL is sourced in `internal/storage/queries` and generated by `sqlc`.
- Application services own `WithTransaction` scope.
- Repository methods map database errors through `platform/database`.
- Game state updates use version conditions and explicit row locks.
- Python must not import this package or receive `mv_core` write credentials.
