# Contract Examples

`manifest.json` maps each fixture to a definition in
`json-schema/mysteryverse.schema.json`.

All fixtures are validated in the Python, TypeScript and Go contract layers.

Task 5 frontend mock fixtures:

- `auth-session.json`: successful register/login payload.
- `room-projection.json`: waiting-room member projection.
- `room-message.json`: independent `room_chat` message payload.
