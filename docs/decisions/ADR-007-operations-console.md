# ADR-007：运营审核后台

- 状态：Proposed
- 日期：2026-11-21
- 影响范围：后台 API、Admin Web、权限、审核、举报、封禁、审计、公开发布

## 决策

基础运营审核后台是公开 MVP 的发布门禁，但不要求第一阶段完成复杂工作流。

内测 MVP 可以使用受控的人工审核流程。公开 MVP 至少必须具备：

- 剧本上架、下架和审核状态管理。
- 举报查看、定位、处理和结论记录。
- 用户禁言、封禁和解除。
- 游戏异常和 incident 查询。
- AI 生成内容审核与阻断处理。
- 管理员 RBAC/ABAC、审批入口和不可变审计日志。

后台 API 与玩家公共 API 分离，不得通过玩家 Token、房主权限或普通运营查询
读取角色本、私聊、身份表或真相。

## 权限

至少区分：

- `content_reviewer`
- `support_agent`
- `security_auditor`
- `platform_admin`

敏感 D2-D4 访问必须使用显式 scope、理由、时效和审计；高权限操作支持审批或
双人复核。后台权限不能从玩家权限继承。

## 审计

所有发布、下架、审核、举报处理、禁言、封禁、敏感访问和事故操作写入
`audit_logs`。审计不保存私密正文，只保存对象 ID、scope、结果、理由摘要和哈希。

## 发布门禁

公开 MVP 缺少上架/下架、举报处理、用户处置、事故查询、AI 内容审核或审计
日志时，不得上线。后台页面不可用时，不能以玩家 API 临时替代。
