# ADR-009：异步增强能力

- 状态：Accepted
- 日期：2026-11-21
- 影响范围：图片生成、AI 复盘点评、任务系统、UI、成本、P0/P1 依赖

## 决策

图片生成和 AI 复盘点评属于 P1 可选异步增强：

- 不阻塞游戏创建、状态机、投票、结算或复盘规则时间线。
- 失败不得导致游戏失败或结果不可用。
- 必须有状态查询、失败记录、幂等、超时、重试和降级。
- 默认关闭或受配额控制。

## P0

- 房间管理。
- 游戏状态机。
- 玩家身份与权限。
- Agent 推理核心。
- 实时通信。
- 投票与结算。
- 核心事件持久化。
- AI DM 模板降级。

## P1

- AI 场景图片生成。
- AI 复盘点评。
- 高级叙事增强。
- 额外视觉效果。

任何人不得让 P0 任务硬依赖 P1 任务。UI 可以预留状态和入口，但必须在能力
关闭时保持核心流程可用。

## 失败与超时

- 子任务使用父任务剩余预算，不得获得超过父 deadline 的超时。
- 重试次数必须有限；语义拒绝和安全拒绝不自动重试。
- 图片失败使用占位或隐藏资产，不影响文本候选发布。
- AI 点评失败保留结构化结算和时间线，点评状态显示 `unavailable|pending|ready`。
- 所有失败写入任务状态、artifact/usage 和安全事件；不得写入游戏结果。

## 影响

- 图片节点是可关闭分支，不进入文本候选发布阻断门禁。
- 结算页只依赖规则结果；AI 点评单独加载。
- TASKS 中 P0 集成任务不得把 P1 任务作为完成前置。
